# 🕯️ ECHOES — Memories Never Die

ECHOES is a local-first AI memory keeper that allows users
to preserve personal memories, photographs, and meaningful
stories, then interact with them using a locally running AI model.

## Features

- Preserve personal memories and photographs.
- Browse and search saved memories.
- Ask questions about saved memories using AI.
- Local SQLite database for memory storage.
- Local AI inference through Ollama and Gemma 4.
- No cloud AI API required.

## Tech Stack

- Python
- Streamlit
- SQLite
- Ollama
- Gemma 4

## Requirements

- Python 3
- Ollama
- Gemma 4 model
